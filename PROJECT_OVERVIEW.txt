🚀 QUICK START (30 Seconds)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Install dependencies:
   $ pip install -r requirements.txt

2. Run the app:
   $ streamlit run app.py

3. Visit in browser:
   • Customer: http://localhost:8501/?table=1
   • Kitchen:  http://localhost:8501/

✨ That's it! App opens automatically.
